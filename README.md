## 👨‍💻 About Me

I'm a **.NET Developer** focused on building and maintaining scalable, database-driven enterprise applications. My primary expertise is in **C#, ASP.NET Core MVC, ADO.NET, SQL Server, REST APIs, JavaScript, jQuery, and AJAX**, with additional experience across the **MERN and Angular ecosystems**.

### Currently at Daewoo Pakistan

Currently engineering core business platforms supporting fleet operations, EV management, finance, and daily operational reporting.

* 🚍 **EV Management System (EVMS) & Fastex Web Platform** — Developing and supporting enterprise applications using **ASP.NET Core MVC (.NET 6), C#, ADO.NET, SQL Server, JavaScript, jQuery, AJAX, and Bootstrap**.
* 🚗 **Fleet, Vendor & Insurance Management** — Developed end-to-end workflows for **vehicle, vendor, owner, insurer, vehicle type, and policy management**, backed by SQL Server stored procedures and AJAX-driven interfaces.
* 🔐 **User & Access Management** — Implemented **role-based permissions, rights-driven UI visibility, session-based access control, and secure password management workflows**.
* 📊 **Finance & Operations Daily Feed** — Maintain a multi-business reporting platform covering **Finance, Urban, FastEx, Fueling, and EBS**, including data validation, duplicate-submission safeguards, data binding, and daily operational reporting.

### Previously at Nova Soft Tech

Delivered **5+ production-level applications** across the **.NET and MERN ecosystems**, including:

* 🛒 **E-Commerce Platform** — N-Tier architecture, Repository Pattern, Unit of Work, ASP.NET Core Identity, AJAX search, product approval workflows, and role-based authorization.
* 🏦 **Banking & Payroll System** — Secure transaction processing with **JWT authentication**, role-based access, administrative dashboards, and automated payroll calculations.
* 🍔 **Food Ordering API** — RESTful backend using **Node.js, Express.js, and MongoDB**, covering menu management and the complete order lifecycle.
* 🔐 **Authentication Service** — Standalone authentication system using **JWT, bcrypt, protected routes, and middleware-based authorization**.
* 🌐 **VPN Application Frontend** — Responsive **Angular/TypeScript** frontend with a modular component-based architecture.
